The world artwork is derived from Natural Earth's 1:110m land polygons:

- Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
- License: public domain, https://www.naturalearthdata.com/about/terms-of-use/

`world-land.svg` is an equirectangular illustration cropped to 85°N–60°S. `world-land.png` provides the same artwork for browsers with SVG disabled. Both are served locally. Markers use approximate public relay city coordinates from `src/data/relays.json`; bridge locations are not included.
